# 索玛家常菜 · 家庭点菜微信小程序

家人共用一份菜单：挑菜 → 核对食材 → 下单 → 采购 → 做饭 → 开饭，全家实时看到进度。

基于微信小程序原生框架和微信云开发，不需要自己的服务器和域名。

## 功能一览

| 模块 | 功能 |
|---|---|
| 家庭 | 创建家庭 / 邀请码加入 / 分享链接邀请；管理员可改名、重置邀请码、转让管理员、移出成员；成员退出、管理员解散家庭 |
| 账号 | 微信身份自动识别（云函数获取 openid，无需手动登录）；头像昵称使用微信官方的头像昵称填写能力 |
| 菜单 | 左侧分类 + 「常点」智能分类；搜索菜名、食材、标签；一键「想吃」；菜品详情（照片、标签、热量、蛋白质、食材、分步做法、点过次数） |
| 下单 | 已选菜品份数调整；用餐日期、餐次、人数、备注；食材核对（勾选家里已有的），一键复制采购清单 |
| 订单 | 进行中 / 已完成 / 全部；状态流转：已下单 → 采购中 → 制作中 → 已完成（可取消）；食材逐项打勾、全家同步；订单动态记录；再来一单；自动刷新 |
| 菜品管理 | 新增 / 编辑 / 删除菜品，上传照片（自动压缩）；分类新建、重命名、排序、删除 |
| 来访 | 每个家庭有独立的只读**访问码**（不能用来加入家庭）；凭访问码浏览别人家的菜单（看不到订单）；给菜品点赞；一键把菜加入自己家的「收藏」分类（照片、食材、做法一起复制）；管理员可开启「开放浏览」，让菜单出现在别人「串门」页的随机推荐里；「谁来过」按天记录访客、点赞和收藏 |
| 消息提醒 | 可选：新订单通知家人、订单状态变化通知下单人（微信订阅消息） |
| 安全 | 所有数据读写都经过云函数，按家庭隔离、做权限校验；文本内容接入微信内容安全检测 |

## 目录结构

```
├── project.config.json          # 开发者工具项目配置（填 AppID）
├── miniprogram/                 # 小程序前端
│   ├── app.js / app.json / app.wxss
│   ├── utils/config.js          # ★ 填云环境 ID、小程序名称
│   ├── utils/                   # 接口、会话、购物车、菜单缓存等
│   ├── components/              # 菜品封面、空状态组件
│   ├── images/tab/              # 底部导航图标
│   └── pages/
│       ├── welcome              # 首次进入：填写资料、创建/加入家庭
│       ├── menu                 # 菜单（tab）
│       ├── cart                 # 确认下单（tab）
│       ├── orders               # 订单列表（tab）
│       ├── profile              # 我的（tab）
│       ├── dish                 # 菜品详情
│       ├── order                # 订单详情
│       ├── manage               # 菜品管理
│       ├── dish-edit            # 新增 / 编辑菜品
│       ├── categories           # 分类管理
│       ├── user-edit            # 编辑个人资料
│       ├── visit                # 串门：输入访问码、开放浏览推荐
│       ├── visit-menu           # 来访：浏览别人家的菜单
│       ├── visit-dish           # 来访：菜品详情、点赞、加入菜谱
│       └── visitors             # 谁来过
└── cloudfunctions/api/          # 云函数（统一入口）
    ├── index.js                 # 路由
    ├── settings.js              # ★ 订阅消息模板（可选）
    ├── seed.js                  # ★ 新建家庭时导入的示例菜单
    ├── handlers/                # 用户、家庭、菜品、订单、来访业务
    └── lib/                     # 数据库、内容安全、消息推送等
```

## 你需要手动填写的内容

| 内容 | 位置 | 状态 |
|---|---|---|
| 小程序 AppID | `project.config.json` 的 `appid`（或导入项目时填写） | 已填写 |
| 云开发环境 ID | `miniprogram/utils/config.js` 的 `CLOUD_ENV_ID` | 已填写 |
| 小程序名称 / 菜单页标语 | `miniprogram/utils/config.js` 的 `APP_NAME`、`SLOGANS` | 可选 |
| 订阅消息模板 | `cloudfunctions/api/settings.js` | 可选 |
| 示例菜单 | `cloudfunctions/api/seed.js`，或上线后在小程序「我的 → 菜品管理」里维护 | 可选 |

> AppID 和环境 ID 不是密钥，但如果仓库是公开的，可以只在本地填写、不提交。

## 部署步骤

### 1. 准备

1. 在 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序，拿到 **AppID**。
2. 安装最新版 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。

### 2. 导入项目并开通云开发

1. 开发者工具 → 导入项目 → 选择本仓库根目录 → 填入 AppID。
2. 点击工具栏「云开发」→ 开通 → 创建环境，复制 **环境 ID**。
3. `miniprogram/utils/config.js` 中已填写环境 ID `cloudbase-d7gfqekry71bb2748`，确认开发者工具右上角选中的是这个环境。

### 3. 部署云函数

1. 在左侧目录树右键 `cloudfunctions/api` → **上传并部署：云端安装依赖**。
2. 建议在「云开发控制台 → 云函数 → api → 版本与配置」里把**超时时间改为 20 秒**。默认 3 秒，解散家庭这类批量操作可能不够用。

数据库集合（`users`、`families`、`dishes`、`orders`、`likes`、`visits`）会在第一次登录时**自动创建**，不需要手动建。
小程序端不直接访问数据库，可以把这些集合的权限都设为「仅管理端可读写」，这样更安全。

> 以后每次更新代码，都要重新右键 `cloudfunctions/api` →「上传并部署：云端安装依赖」，新功能才会生效。

### 4. 本地预览

点「编译」：首次进入会到欢迎页，填写昵称、创建家庭（可勾选导入示例菜单）后就能使用。
点「预览」扫码，用另一个微信号输入邀请码加入，即可体验多人同步。

### 5. 订阅消息（可选）

1. 公众平台 → 功能 → 订阅消息 → 选用两个**一次性订阅**模板，比如「新订单通知」和「订单状态通知」。
2. 把模板 ID 和字段名填进 `cloudfunctions/api/settings.js`（文件里有详细说明），然后重新部署云函数。
3. 用户在提交订单、完成订单，或点「我的 → 订单提醒」时授权，之后就能收到通知。

不配置时，「我的」页不显示订单提醒入口，其他功能不受影响。

### 6. 发布上线

1. **用户隐私保护指引**（必须）：公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引，勾选并说明用途：
   - 用户信息（微信昵称、头像）：用于在家庭成员中展示身份
   - 选中的照片或视频、摄像头：用于上传菜品照片
   - 剪切板：用于复制邀请码和采购清单
2. **服务类目**：建议选择「生活服务」或「工具」下的合适类目。
3. 开发者工具 → 上传 → 公众平台「版本管理」提交审核 → 审核通过后发布。
4. 审核备注可以写：「家庭内部点菜和备菜工具，用户需创建或通过邀请码加入家庭后使用」，并提供一个测试邀请码给审核人员。

## 常见问题

**提示「请先在 utils/config.js 中填写云开发环境 ID」**：没有填 `CLOUD_ENV_ID`，或者填完没有重新编译。

**提示「云函数 api 未部署」**：按第 3 步上传并部署云函数，并确认开发者工具右上角选中的云环境就是你填写的环境。

**修改了云函数代码**：需要重新右键「上传并部署」才会生效；如果改的是 `settings.js` 或 `seed.js`，也同样要重新部署。

**菜品图片存在哪里**：存在云开发的云存储 `dishes/` 目录；删除菜品或更换图片时会自动清理旧图。

**如何自定义示例菜单**：编辑 `cloudfunctions/api/seed.js` 并重新部署。只对之后新建的家庭生效，已有家庭请直接在小程序里修改菜品。
